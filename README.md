# ⚡ Electric Vehicle Info System

A Core Java-based project to provide information about electric vehicles. Helps users explore and understand various types of EVs.

## 🧰 Tech Stack
- Java
- OOP Concepts
- Console-based UI

## 🔍 Features
- Info about different EV categories
- Simple console navigation

## ▶️ How to Run
1. Clone the repo
2. Open in any Java IDE
3. Run the main class
